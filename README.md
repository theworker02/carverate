# carverate

Carve structured JSON rate payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/carverate/

## Install / run

```bash
git clone https://github.com/theworker02/carverate.git
cd carverate
node src/cli.js
node --test
```
